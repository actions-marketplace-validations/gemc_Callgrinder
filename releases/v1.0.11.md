# Callgrinder Release v1.0.11

This version includes:

- Matching information in category and top-routine tables.
- Direct caller counts and nearest project callers for any application.

<br/>

# Release notes

- Use the same columns in both tables: category, source, routine or entry symbols, inclusive and self
  Mcycles, percentages, incoming calls, direct callers with counts, and nearest project callers.
  Category rows aggregate their matched routines; ranked rows describe individual routines.
- Report direct callers with recorded call counts and trace upstream through runtime functions to the
  nearest project caller on each branch. General runtime-name inference works without framework-specific
  rules; optional `project_callers` regexes match routine names, source paths, or owning binary/library paths.
  Distances describe observed call-graph edges; upstream callers are not assigned inferred call counts.
- Include source and caller information in JSON results for both tables and escape regex alternation in
  Markdown cells so category symbols cannot split table columns.
