# Callgrinder Release v1.0.1

This version includes:

- A `--from-callgrind` path that summarizes an existing callgrind file without running a command.

<br/>

# Release notes

- `profile` mode (and the `callgrinder` CLI) accept `--from-callgrind <file>` / the `from-callgrind` action
  input: Callgrinder annotates and reports an existing `callgrind.out` file instead of running the command
  itself. This lets a caller run `valgrind` its own way — passing complex, space-containing arguments as a
  shell array with no re-quoting — and hand the resulting profile to Callgrinder for the summary.

<br/>

## Detailed list of changes and fixes

- Factored the annotate/render/write step of `profile` mode into a shared `summarizeCallgrind` routine used by
  both the full run and the `--from-callgrind` path.
