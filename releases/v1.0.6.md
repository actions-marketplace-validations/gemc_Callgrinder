# Callgrinder Release v1.0.6

This version includes:

- Reliable self-cost shares and a clearer distinction between direct and inclusive costs.

<br/>

# Release notes

- Restricted parsing to the function table so source annotations cannot repeat callee costs as self cost.
  The top-routines table now shows only direct shares of the run, with listed and remaining totals.
  Category inclusive percentages are explicitly labelled as overlapping and non-additive.

<br/>

## Documentation

- Reworked the quickstart to profile the user's executable, with debug-build prerequisites, explicit output
  paths, and local and GitHub Actions report examples.
- Explained percentage accounting and how to regenerate summaries from existing raw profiles.

<br/>

## Tests

- Added regression coverage for source-annotation contamination and additive self-cost shares.
