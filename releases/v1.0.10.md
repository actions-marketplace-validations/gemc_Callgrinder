# Callgrinder Release v1.0.10

This version includes:

- Correct call counts for C++ routines with ABI tags.
- Source filenames before routine names and call counts in the last column.

<br/>

# Release notes

- Preserve ABI tags such as `[abi:cxx11]` when reading raw function names so incoming call counts
  match the routines in the summary and JSON output.
- Place **Source / package** before **Routine** and **Calls** after **Self %** in the top-routines table.
  Source filenames and fallback binary/library names omit their directory paths.

<br/>

## Tests

- Verified ABI-tagged symbols, recursive incoming calls, source basenames, column order, and propagation
  of source names and call counts into combined Markdown and JSON reports.
