# Callgrinder Release v1.0.8

This version includes:

- Hotspot selection based on direct routine costs.

# Release notes

- Select the top routines by highest self cost, then display them by descending inclusive **% of run**.
  Thread wrappers with high inclusive cost no longer displace routines doing more direct work.
  **% of run** remains before **Self %**, and JSON results follow the same selection and ordering.
