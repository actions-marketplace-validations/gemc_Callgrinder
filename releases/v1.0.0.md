# Callgrinder Release v1.0.0

This version includes:

- A zero-dependency Node.js 24 GitHub Action and local `callgrinder` CLI.
- `profile`, `report`, and `discover` modes for single runs and distributed fan-out.
- A per-category CEst table (inclusive and self cost) plus a top-routines-by-self-time table.
- Config-driven categories: fixed `match` symbols and discovered `discover` families.

<br/>

# Release notes

- Profiles a command under `valgrind --tool=callgrind` with cache and branch simulation, then reports cost as
  CEst (cycle estimation, `Ir + 10·L1_misses + 100·LL_misses`).
- The category table shows each category's **inclusive** cost (entry point plus callees, overlapping) and its
  **self** cost (cycles executed directly in the entry function, non-overlapping).
- Categories are supplied as JSON: `match` names one entry symbol; `discover` captures a class in group 1 and
  reports one row per class, so per-detector or per-plugin costs appear automatically.
- The top-routines table ranks individual routines by self cost, strips callgrind call-count suffixes and
  summary artifacts, and labels unresolved addresses with their object.
- Emits a job-summary section, a `callgrind.out.<name>` artifact, a partial JSON per profile, and — in report
  mode — a combined `summary.md`, a per-category `categories.csv`, and an aggregated JSON.

<br/>

## Examples

- `examples/gemc3.json` — GEMC3 categories (digitization, SRO, field evaluation, swimming, output).
- `examples/gemc2.json` — GEMC2 categories (`_HitProcess` digitization, `_output` writers, field maps).

<br/>

## Tests

- `npm run check` (node `--check` on the entry points) and `npm test` (`node --test`) cover the callgrind
  parser, name cleaning, category aggregation, and rendering.

<br/>

## Supported platforms

- Linux runners with `valgrind` (providing `callgrind_annotate`) and Node.js 24 or newer. Profiling is not
  available on Windows.

<br/>

## Dependencies

- Node.js 24+. No npm runtime dependencies. `valgrind` must be installed on the runner or baked into the image.
